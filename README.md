# 🍕 SQL Pizza Sales Analysis

## Project Overview

This project analyzes a pizza sales dataset using SQL to extract meaningful business insights. The analysis focuses on customer ordering patterns, revenue generation, product performance, and sales trends. SQL queries were used to solve real-world business problems and support data-driven decision-making.

---

## 🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- Pizza Sales Dataset

---

##  Project Objectives

- Analyze overall pizza sales performance.
- Calculate total revenue generated.
- Identify top-selling pizzas and popular sizes.
- Analyze customer ordering behavior.
- Determine category-wise sales distribution.
- Identify peak ordering hours.
- Perform revenue and trend analysis.

---

##  Database Schema

The project consists of four relational tables:

- Orders
- Order_Details
- Pizzas
- Pizza_Types

These tables are connected using Primary Keys and Foreign Keys to perform relational analysis.

---

## Business Questions Solved

### Basic Analysis

- Retrieve the total number of orders placed.
- Calculate the total revenue generated from pizza sales.
- Identify the highest-priced pizza.
- Identify the most common pizza size ordered.
- List the top 5 most ordered pizza types.

### Intermediate Analysis

- Find the total quantity sold for each pizza category.
- Determine the distribution of orders by hour.
- Analyze category-wise pizza distribution.
- Calculate the average pizzas ordered per day.
- Identify the top 3 pizza types based on revenue.

### Advanced Analysis

- Calculate the percentage contribution of each pizza type to total revenue.
- Analyze cumulative revenue over time.
- Determine the top revenue-generating pizzas for each category.
